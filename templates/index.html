📊 Executive summary
Agent 1 — Extraction Agent
1. Document reading
Identifies company name, reporting period, currency, and report type from the uploaded PDFs.
2. KPI extraction
Extracts all 10 required financial KPIs from each report: Revenue, EBIT, Operating Margin, Cash Metric, Net Liquidity, Return on Capital, Cost of Capital, EPS, Dividend, Market Cap.
3. KPI mapping
Maps company-specific terminology to standardized KPI names. Records each substitution for transparency.
4. Confidence scoring
Tags each data point: High (found directly), Medium (calculated), Low (estimated). Prevents overconfidence in uncertain figures.
Agent 2 — Analysis Agent
1. Data combination
Merges all three Agent 1 outputs into a single unified table with 6 data columns (full year + quarter for each company).
2. Mapping consolidation
Deduplicates and organizes all KPI mapping notes by company, creating a single reference for terminology differences.
3. Cross-company analysis
Compares revenue scale, profitability, cash generation, liquidity, and capital efficiency across all three OEMs.
4. Executive insights
Produces 5 to 7 actionable insights with specific numbers, identifying strengths, risks, and an overall financial health ranking.
Agent name: AFIA — Automotive Financial Intelligence Agent
Architecture: Multi-agent pipeline. Agent 1 (Extraction) runs per company. Agent 2 (Analysis) runs once across all three.
Model: Gemini 2.5 Flash via Google Generative AI API
Input: Up to 6 PDF files (2 per company) sent as base64-encoded documents
